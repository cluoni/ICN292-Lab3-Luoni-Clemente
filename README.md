## Informacion del Laboratorio
En este repositorio se encuentran los archivos utilizados para el Laboratorio 3 de ICN292. El trabajo consiste en desarrollar un sistema en n8n para recibir y clasificar solicitudes de devolución según las reglas establecidas.
## Archivos
**LAB3.json**
Este es el workflow principal, recibe la solicitudes mediante el Webhook y las clasifica segun las reglas del proceso establecidas.

**lab3emisor.json**
Este workflow se usa para enviar solicitudes a LAB3 mediante POST.

**lab3resumen.json**
Este workflow toma todas las solicitudes diarias y genera un resumen funcional.

**Informe PDF**
Es el informe final del laboratorio con el desarrollo y los resultados de lo realizado.

## Reproducción ##
Para reproducir el archivo .json de lab3emisor, es necesario añadir un cuerpo de .json ya que este fue dejado en vacio itencionalmente para que no reproduzca una solicitud cualquiera al instante.
**Informe word**
Lo mismo que lo anterior pero en caracter editable.
